# Chapter 2 Lab: AI/ML/DL Fundamentals and GPU Architecture

**Estimated time:** 12 minutes

## Exercise

Architecture Comparison Lab: Analyze provided diagrams comparing CPU (8-16 cores, complex control) vs GPU (thousands of simple cores, SIMT execution). Calculate theoretical FLOPS for matrix multiplication on CPU vs GPU. Review sample confusion matrix and compute precision/recall/F1 manually.

## Key takeaway

Training maximizes throughput with large batches and high inter-GPU bandwidth; inference minimizes latency with optimized models—remember this dichotomy for infrastructure sizing questions.
